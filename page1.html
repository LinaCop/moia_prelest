Шаг 1. Выберите профессию

Подбор средств индивидуальной защиты

Выберите профессию, отметьте фактически выданные СИЗ и получите результат в сопоставлении с обязательными нормами. Форма предназначена для последовательной и понятной проверки обеспеченности средствами защиты.

  • поиск по коду или названию профессии
  • просмотр всех обязательных СИЗ по типам
  • итог с дефицитами и блоком ЛПП

Что важно учитывать

Результат показывает типовые нормы и сведения, загруженные для конкретной профессии.

  • проверяйте фактическое количество выданных средств;
  • при необходимости уточняйте данные у работодателя;
  • информация по ЛПП может требовать уточнения по СОУТ.
Например: 1799 или лаборант

Выберите профессию, чтобы просмотреть перечень обязательных СИЗ в соответствии с установленными нормами.
